# Fairy 系统重构设计

2026 年 11 月 17 日。

先阅读 Word 或 Markdown 正文。红字要求已逐项映射到功能设计和验收，原标注文档未改动。

本版取消固定十系统边界，按体验、认知、记忆与世界、学习与进化、行动、运行治理六个平面组织。正文涵盖识海、自我与情绪、世界模型、来源记忆、目标调度、自主学习、自主进化、可装载技能、Mac 操控、后台配置、多端卡片及原形象桌宠。

- diagrams/：13 张流程图，分别提供 PNG、SVG 与 Mermaid 可编辑源文件。
- screenshots/：15 张页面截图，包括 10 个管理后台页面与 Mac、iOS 端页面（v2.2 重制）。
- prototype/index.html：本地管理后台入口；desktop-chat.html 为桌面端，m-chat.html 为手机端。
- prototype/support-*：沿用上一版的手机互传、搜索和设置页面，保证原型导航完整。
- examples/：配置、技能清单、学习目标与确认卡片的 JSON 示例。
- Markdown：可编辑的方案正文，图片使用相对路径。

原型支持页面导航、按钮反馈和本地配置预览；保存配置不会应用到真实服务器。示例技能尚未安装到 Fairy，Mac 权限未改变，未启动摄像头或执行桌面操作。实际部署按方案 P0 至 P5 逐阶段验证。

阅读时重点检查第 05 至 16 章的认知、学习与执行机制，以及第 19 至 22 章的后台、配置、数据和 API 契约。公开上游实现与 Fairy 新设计已分开说明。
