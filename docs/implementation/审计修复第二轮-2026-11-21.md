## 修复清单

1. **云计费未知用量不再按 0 计**（`models.py settle/_cloud_usage`）：云返回缺少 usage 时，`charge_status="unknown"`，按预留金额（`reserved_microcents`）计入当日预算，并单独统计 `unknown_charges`。此前缺失 usage 会被当作 0 费用，导致预算被绕过。
2. **云出口 DNS 钉扎防重绑定**（`models.py public_cloud_address/pinned_request/_json`）：真实出网前解析域名，任一地址非公网即拒绝（`cloud_destination_denied`）；解析失败视为 `cloud_unavailable`。请求 URL 改写为已核验 IP，保留 Host 头与 TLS SNI，杜绝校验后 DNS 重绑定到内网。MockTransport 测试路径不触发解析。
3. **受控建文件拒绝符号链接目标**（`mac_bridge.py create_file`）：目标已存在或为符号链接（含悬空链接）一律 409 `file_already_exists`，配合 `O_EXCL|O_NOFOLLOW` 与目录 fd 钉扎，防止借链接覆盖白名单外文件。
4. **技能授权中途失效则扣发结果**（`skills.py invoke`）：完成事务内重新校验授权状态与有效期，过期/撤销即 409 `skill_grant_expired`，调用记录标记 failed 并发出 `skill.invocation_failed` 事件。注意：已发生的只读检索等副作用无法回滚，本修复保证的是结果不外发、审计留痕。
5. **同库恢复可用**（`maintenance.py restore_database`）：`pg_restore` 增加 `--clean --if-exists`，允许把备份恢复回原数据库（此前因对象已存在而失败），保留 `--no-owner --no-acl --exit-on-error`。
6. **备份状态文件防临时符号链接**（`maintenance.py write_status`）：临时文件用 `O_CREAT|O_EXCL|O_NOFOLLOW` 创建，被抢占符号链接时清理后重试一次，成功后原子替换，权限 0600。
