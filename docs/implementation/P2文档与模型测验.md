# P2 继续交付：文档提取与模型测验

## 本轮功能

文件投喂支持 UTF-8 TXT/Markdown、带文本层的 PDF 和 DOCX，沿用 1 MiB 输入与 256000 字符提取上限。PDF 最多100页，记录页号；DOCX 记录正文段落号，包含表格内段落，不执行宏、外部资源或链接。上传后保留原文件SHA256、格式和提取位置，worker分块引用对应页/段落。原始二进制文件不长期保存，用户应保留原文件用于核对。

二进制解析在单独进程执行，不继承模型密钥等环境变量；限制CPU时间、输出文件大小和解析时长，父进程监控RSS。Linux额外限制地址空间，macOS采用RSS监控，不宣传成操作系统安全沙箱。PDF解压工作量、DOCX ZIP总展开量与XML大小另有限制；拒绝XML实体、宏包、加密PDF和无可提取文字的扫描件。超时或资源超限返回失败，不把空文档作为阅读完成。

PDF文字提取不等于完整版面理解，不提供OCR、表格结构或公式准确性保证。提取依据采用 [pypdf 官方说明](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)，用户仍需核对原文。

## 学习测验

新增「学习测验」页面：预先填写题目、每行一个的备选答案、正确序号及精确原文依据。每份1–10题，每题2–6个选项。标准答案只存在服务端题库，不进入模型请求。

选择开卷或闭卷后，由当前本地 Ollama 模型作答，程序按固定答案精确计数。开卷只提供所有者选定的原文摘录，闭卷不提供材料；两者都不读取个人记忆或完整聊天，不调用云模型。每次记录模型、配置版本、题库/来源版本、结果和评分方法。

答题响应必须包含每题恰好一个有效整数选项。缺失、重复、越界、布尔值或无效结构均不能得到有效分数。来源删除/复核变化、模型配置变化或取消后拒绝迟到计分。模型派发复用持久调用账本，同一幂等提交不重复推理，失败不自动重试；重启后的过期派发进入结果未知。

这些是“固定题目上的答题表现”，不是模型自评，也不是参数训练、长期掌握或通用迁移认证。题目与标准答案由所有者编写，其质量与是否构成合格留出集尚需独立评审。单题的开闭卷差异不能证明已经学会。

## 新增接口

POST/GET `/v2/learning/quizzes`、POST `/v2/learning/quizzes/{id}/runs`、GET `/v2/learning/assessment-runs`、POST `/v2/learning/assessment-runs/{id}/cancel`。文件上传仍使用 `/v2/learning/files`，无需更换接口。
