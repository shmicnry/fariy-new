# 运行底座与自主能力增强

日期：2026-11-17。

本轮完成不依赖外部账号或真机授权的能力，并把 API 与 worker 安装为当前 Mac 的用户级 LaunchAgent。

## 常驻服务

- API 与 worker 独立运行，端口为 `127.0.0.1:8010`。
- worker 使用单实例锁、原子心跳文件、异常退避和 SIGTERM 停止处理。
- `/v2/worker/status` 返回 PID、心跳、循环次数、处理结果和错误类别。
- 当前 Mac 已安装：
  - `io.fairy.api`
  - `io.fairy.worker`
- 运行副本和状态位于 `$HOME/Library/Application Support/Fairy`，避免后台进程访问 Documents 时被 TCC 卡住。
- owner token 随机生成并保存到 `$HOME/Library/Application Support/Fairy/api-token`，权限为 `0600`；LaunchAgent plist 不包含令牌。
- 每日 03:00 使用 `pg_dump --format=custom` 备份 PostgreSQL，默认保留 14 天；备份位于 `$HOME/Library/Application Support/Fairy/backups`。

```sh
scripts/fairy_worker_service.sh status
scripts/fairy_api_service.sh status
scripts/fairy_backup_service.sh status
scripts/fairy_backup_service.sh run
```

## 全页面同步与通知

- 登录后读取事件头游标，并通过 SSE 从本地持久游标继续订阅。
- 记忆、来源、学习、技能、自主、进化、审批、笔记和卡片事件会更新相应页面。
- 表单存在未提交内容时不会强制重绘，而是显示刷新提示并保留草稿。
- 新增通知中心、未读角标、全部已读、清空和事件跳转。
- 浏览器授权后可在页面后台显示系统通知；卡片提醒在页面或已安装 PWA 活跃时触发。

## 本地语音与 OCR

- macOS `/usr/bin/say` 生成 22.05kHz WAV，音频不落业务数据库。
- 浏览器录音优先调用本地 Whisper；未配置模型时退回浏览器 Web Speech。
- `FAIRY_WHISPER_CLI` 和 `FAIRY_WHISPER_MODEL` 可启用本地 ASR。
- Vision OCR helper 支持 PNG、JPEG、HEIC 和 TIFF，限制图像大小、OCR 行数和文本长度。
- 只读 Mac helper 可探测真实辅助功能/屏幕录制权限，并读取经过深度和节点限制的 Accessibility Tree。

## 检索

- 对话记忆使用保守的词法 + 本地字符向量混合召回，避免仅共享一个汉字造成误召回。
- 学习检索使用本机 Ollama `bge-m3:latest` 做神经向量重排，向量缓存在本地数据库。
- 模型不可用时自动退回本地字符混合检索。
- 语义重排只用于学习资料与技能检索；已确认个人记忆仍保留更严格的召回边界。
