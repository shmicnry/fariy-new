## 已修复缺漏

| 问题 | 影响 | 修复 |
|---|---|---|
| 文件幂等摘要使用规范化文本 | BOM 等不同原始字节可能共享缓存 | 文件提交以原始 Base64 字节计算摘要；BOM 差异重放返回 409 |
| 课程完成按练习记录创建顺序判断 | 较早练习最后复核通过仍可能被误判失败 | 以最近一次 `reviewed_at` 评分为准 |
| 练习改判失败不撤销掌握 | 旧知识继续出现在习得知识中 | 撤销课程掌握和关联习得条目，并记录审计事件 |
| 来源争议后仍可归纳习得知识 | 不可信来源继续产生学习结论 | 获取知识前重新检查来源和最近练习 |
| 最终课程确认可使用任意说明文字 | “看过”也能成为来源依据 | 文件/链接课程要求逐字原文证据 |
| 测验取消不结算模型调用 | 页面中断但调用日志仍显示已开始 | 取消时把在途调用标记 `unknown`，迟到结果不计分 |
| 效果页漏计模型测验 | 人工练习和模型测验数据分离 | 合并当前有效模型测验，单独统计已失效历史 |
| 失效来源的测验与课程仍像可用 | 用户操作到最后才收到 409 | 接口返回 `source_eligible`，页面禁用并明确标注 |
| 来源、知识主张和测验缺少撤回入口 | 无法只删除错误对象 | 后台支持删除来源、撤回主张和撤回测验，保留级联失效 |
| 来源失效后幂等重放返回旧有效分数 | 旧结果可能重新看起来有效 | 幂等重放刷新测验、主张和作答记录的当前来源状态 |

同时修正了练习提交仍使用旧来源判断、模型作答取消状态、效果记录失效区分及错误提示可读性。

## 仍然存在的缺漏与边界

| 项目 | 当前状态 |
|---|---|
| 扫描型 PDF / OCR | 未实现；空文本 PDF 明确失败，不伪造读取成功 |
| 旧版 DOC | 未支持，只支持 DOCX |
| 图片、音频、视频 | 未支持，没有 ASR、视觉观察或时间戳引用 |
| PDF/DOCX 版面理解 | 只提取文本；表格、公式、阅读顺序和复杂排版不保证正确 |
| 真实公网链接采集 | 当前机器 DNS 结果被公网地址规则阻止；保留安全拒绝，未放宽私网限制 |
| 自动出题与客观能力认证 | 题目和答案由所有者提供；没有独立评估集、统计显著性或多模型对照 |
| 通用学习迁移 | `generalization_verified` 始终为 false，单题分数不能证明学会 |
| 语义 / 向量检索 | 仍为词法检索；无嵌入、ANN 索引或实体图 |
| 实体消歧与复杂冲突 | 只对完全同名的主题/属性显示显式冲突，不做同义词或上下文消歧 |
| 多媒体与原生 App | 属于后续阶段，本审计未将其标记完成 |
| 真实云模型 | 配置和模拟测试已存在，仍需用户提供真实地址、模型和密钥后验收 |
| GitHub Actions | 账号账单/支出限制仍阻止云端 runner 启动；本机验证独立完成 |
| 容器部署 | Postgres 已完成独立验收，但完整 Docker 网络和 Ollama 宿主连接未验证 |

## 结论

P2 的核心个人学习闭环已达到当前设计可验证的工程边界：所有者投喂材料，Fairy 按出处阅读，所有者用练习和固定题测验核验，错误或争议来源会撤销学习结论。上述剩余项必须继续按独立里程碑验收，不能据此宣称完整自主学习能力已经完成。
