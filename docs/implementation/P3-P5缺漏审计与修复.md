# P3–P5 缺漏审计与修复

日期：2026-11-18。审计范围：`main@0c61d75` 之后的全部后端、Web/PWA、SwiftUI、
macOS bridge、运行脚本、测试和 CI。本文只记录代码与真实环境中可验证的结论。

> 后续自主执行账本迭代将全量回归提升到 131 项，详见
> [自主执行账本与表单保稿](自主执行账本与表单保稿.md)。

## 已确认并修复

### 1. 技能调用状态曾停留在 `running`

技能调用在事务提交后仍修改了已脱离 Session 的 ORM 对象，导致成功调用没有保存
`completed`，失败调用也无法稳定保存 `failed`。现在成功和失败都用调用 ID 在新事务
重新读取记录：

- 成功写入结果与 `completed`；
- 失败写入脱敏错误码、完成时间和 `skill.invocation_failed` 事件；
- 不允许任意异常文本进入持久记录；
- Mac 子进程调用移出事件循环，避免状态、AX Tree 或应用启动阻塞 SSE 与其他请求。

### 2. 自主预算页面会覆盖 Mac 授权

管理端保存自主预算时曾固定提交 `mac_execute: false`，会无意关闭已配置的允许应用
启动能力。现在保存自主设置会保留当前 `mac_execute`。浏览器验收会先配置允许列表，
保存自主预算后再读取服务端配置确认没有被覆盖。

### 3. 设备允许范围缺少输入边界

`mac_allowed_apps` 与 `mac_allowed_paths` 原先只有数组数量上限。现在：

- 应用项会去除首尾空白并去重；
- 拒绝空值、控制字符和超过 500 字符的应用项；
- 路径项会去重，并要求绝对路径、无控制字符且不超过 2000 字符；
- 这些检查发生在配置进入数据库之前。

### 4. 损坏的来源到期时间会击穿读取路径

来源到期字段被人工或迁移损坏时，原先的时区比较可能抛出异常，使记忆召回、检索和
课程列表整体失败。现在无法解析的到期时间按“来源不可用”处理，删除、争议和重新
复核仍可恢复后续可用状态。

### 5. 原生客户端等待时间短于后端模型预算

SwiftUI 客户端原先使用 `URLSession.shared` 的默认 60 秒请求超时，而本地模型默认
允许 90 秒，云副模型还可在之后继续运行。现在使用设备本地临时 URLSession：

- 单次请求超时 330 秒；
- 资源总时限 360 秒；
- 等待网络可达；
- 不持久化网络缓存。

课程人工验证的两个按钮现在共用原文依据的禁用条件，不再允许空依据触发其中一项。

### 6. PWA 缓存边界

Service Worker 现在只缓存成功响应；离线时只对页面导航回退到应用外壳，缺失的脚本、
样式或图片不会错误地收到 HTML。缓存版本提升为 `fairy-shell-v11`。

### 7. 容器端口与当前 Mac 环境冲突

Compose 的宿主端口从 `8000` 调整为 `8010`，避免覆盖这台 Mac 上既有的
`PersonalAI-Connect` 服务。容器内部仍使用 8000，健康检查不变。

### 8. CI 与浏览器验收未覆盖真实风险

- CI 新增 PostgreSQL 16 service，并显式设置 `FAIRY_TEST_POSTGRES_URL`；
- P3–P5 浏览器验收必须提供明确的测试状态目录和数据库 URL，否则拒绝启动 worker，
  防止误连其他数据库；
- worker 会持续处理队列，直到验收课程完成，不再因为更早的历史任务而误报；
- 课程判定请求现在断言成功，不再忽略 409。

## 仍受外部条件限制

1. 真实键鼠注入、AX 自动操作、窗口内容读取和屏幕录制仍保持关闭，需要系统 TCC
   授权、签名身份和独立动作桥验收。
2. SwiftUI 仍缺 Xcode App target、签名、App Store 发布材料、APNs、真机 Keychain
   和麦克风验收。
3. 真实云副模型需要所有者填写供应商兼容地址、模型和密钥；本次没有发出付费请求。
4. Whisper 本地 ASR 需要 CLI 与 GGML 模型；视频通话需要媒体服务和 TURN。
5. 自动公网选题、无人值守发布和真实灰度回滚仍需独立预算、来源白名单、构建隔离和
   回滚演练，不能由当前隔离实验台直接替代。
