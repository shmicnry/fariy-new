# 模型测验草稿与人工确认

日期：2026-11-19。本迭代增加本地模型测题草稿，但不把模型输出直接当作标准答案。

## 工作流

1. 所有者选择仍有效来源并填写逐字原文依据；
2. 本地 Ollama 生成 1–5 道固定选项候选题；
3. 草稿状态为 `pending_review`，`executable=false`；
4. 管理端展示题目、选项和零基正确索引；
5. 所有者修改标题和题目 JSON；
6. 所有者明确确认后，才创建可执行固定题目测验；
7. 拒绝草稿不会创建任何测验。

生成只使用所有者选定的原文摘录，不使用完整个人记忆、历史对话、云端模型或外部知识。
题目生成调用进入模型调用账本，并受本地模型配置与快照失效检查。

## 接口

```text
POST /v2/learning/quizzes/drafts
GET  /v2/learning/quizzes/drafts
POST /v2/learning/quizzes/drafts/{id}/approve
POST /v2/learning/quizzes/drafts/{id}/reject
```

确认后的测验评分规则标记为 `owner_reviewed_model_draft`。开放、闭卷作答仍由确定性程序
按固定答案评分，`generalization_verified` 继续为 false。

## 数据与失效

- 草稿使用来源 revision 快照；
- 生成期间来源删除、复核或版本变化会使草稿失败；
- 逐字依据必须存在于当前有效来源；
- 草稿本身没有执行权限；
- 只有确认后的 quiz 可进入作答流程。

## 验证

- 真实本地 `qwen3:4b` 生成草稿；
- 草稿在确认前不出现在可执行测验列表；
- 所有者编辑后确认创建可执行测验；
- 错误或不存在原文在调用模型前拒绝；
- 模型结构无效时失败且不创建 quiz；
- 浏览器真实 DOCX、开卷、闭卷、模型草稿和人工确认闭环通过；
- 34 个页面状态控件审计通过。

## 边界

- 模型候选题及正确索引可能错误，必须人工核对；
- 当前没有自动生成高质量留出集或统计显著性评估；
- 草稿确认仍不能证明通用学习迁移。
