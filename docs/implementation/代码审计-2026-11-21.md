## 结论

无致命问题(Must fix:0)。两处 Should fix 已当场修复并通过验证;两处 Nice to have 记录在案。

## 已修复(Should fix)

1. **原生端收不到卡片提醒**。worker 已能把到期提醒写入卡片并通过 SSE 推给 Web,但 iOS/macOS 原生 App 只轮询审批,从不拉取卡片,提醒在原生端静默丢失。修复:`APIClient.swift` 增加 `CardItem` + `cards()`;`ContentView.swift` 在 refreshAll 中拉取卡片并对 `remindedAt != nil` 的卡片发本地通知(首次加载建立基线,避免旧提醒轰炸;授权重置时清空已知集合)。
2. **语义嵌入缓存按扫描命中**。`semantic.py` 的缓存查询按 created_at 倒序扫最新 5000 行找 key,窗口外必 miss 且每次 O(n)。修复:缓存改为确定性主键 `embed:<key>` 的 `session.get(Record, …)` 精确查找,写入直接用该主键;删除扫描逻辑与无用 import。新增回归测试 `test_embedding_cache_hit_by_primary_key`。

## 验证过的关键防线(抽查通过)

- link_fetch SSRF:仅 https/443;DNS 全量解析要求全部为公网地址后 pin IP 连接;TLS 校验主机名;不跟随重定向;字节/时间双上限。
- mac_bridge:realpath 归一化限定授权目录,`O_EXCL|O_NOFOLLOW` + dir_fd 防符号链接逃逸,写后 SHA-256 读回校验。
- open_app 白名单、无 shell 拼接。
- 云模型计费:microcents 预留/结算,未知价格按已发生费用入账,不会漏计。
- 密钥 vault:0o600/0o700,端点绑定;备份 sha256 + 恢复演练脚本。
- ScopeLock:迁移内置 owner 行,测试断言恰为 1 行。
- Web 无 innerHTML/eval(`el` 用 textContent);service worker network-first、缓存兜底、永不缓存 `/v2/`。
- 全仓无 SQLite 残留。
