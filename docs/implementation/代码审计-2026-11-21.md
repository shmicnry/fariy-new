1. **原生端收不到卡片提醒**。worker 已能把到期提醒写入卡片并通过 SSE 推给 Web,但 iOS/macOS 原生 App 只轮询审批,从不拉取卡片,提醒在原生端静默丢失。修复:`APIClient.swift` 增加 `CardItem` + `cards()`;`ContentView.swift` 在 refreshAll 中拉取卡片并对 `remindedAt != nil` 的卡片发本地通知(首次加载建立基线,避免旧提醒轰炸;授权重置时清空已知集合)。

## 第二轮深度审计(同日):计费/路由、Mac 范围、SSRF、存储事务、密钥、备份恢复

### 已修复(Must fix)

1. **云计费单位换算错 1000 倍**。价格单位是"美分/百万 token",1 美分 = 1000 微美分;后端 `reserve()`/`settle()` 直接把 `tokens × cents_per_million` 当微美分入账,少除了 1000,费用被高估 1000 倍。真实价位下日预算上限会提前 1000 倍触顶,把云端兜底整个挡死。Web 端此前用 `÷100_000_000` 换算美元(应为 `÷100_000`),恰好抵消了显示误差,掩盖了问题。修复:后端两处补 `(+999)//1000` 向上取整;`p1.js` 两处改回 `÷100_000`;缓存版本 v21→v22。回归测试改用真实量级价格(输入 100¢/M、输出 200¢/M),断言 30+10 token 结算为 5 微美分,旧实现会得到 5000。

### 已修复(Should fix)

2. **过期调用的恢复只在 API 启动时执行**。`recover_stale()` 原先只在 ModelRouter 构造时跑一次;若 API 崩溃期间 worker 存活,过期的云端调用会一直停在 started 状态、占着预留预算。修复:抽出模块级 `recover_stale_invocations(db, service)`,worker 每个周期开头执行一次,summary 增加 `model_invocations_recovered`。新增测试 `test_worker_cycle_recovers_expired_dispatch_without_api_restart`:不重启 API,仅跑一个 worker 周期,断言过期调用转 unknown、turn 转 failed、不重放。

### 复核健全(本轮逐行走查确认)

- **路由/并发**:local-first,升级受 routing+fallback_on 双开关;快照 revision + 配置 CAS;按 (turn_id, phase) 去重;`reserve()` 在 `db.tx()` 内先 UPDATE scope_locks 行,写入串行化,READ COMMITTED 下预留竞态不成立;CancelledError 结算为 unknown;恢复只标 unknown,永不自动重放。
- **密钥 vault**:O_EXCL|O_NOFOLLOW、0600 文件/0700 目录、fsync、端点绑定、mode 校验;密钥不进 SQL/公共 payload/事件流(测试断言)。
- **Mac 范围**:open_app 白名单 + `/usr/bin/open` argv、净化 env、无 shell;files() realpath 收敛只读;create_file 父目录 resolve + dir_fd + O_EXCL|O_NOFOLLOW + 0600 + fsync + SHA-256 读回,256KiB 上限,永不覆盖;ax_tree argv 传 bundle_id,8s 超时。
- **SSRF**:仅 https/443,禁凭证/fragment;DNS 全量解析须全部公网地址,首地址 pin 连接且 SNI=主机名;非 200 拒绝(不跟随重定向);identity 编码、1MiB、20s deadline + 10s socket 超时、UTF-8 强制、剥离 script/style。
- **存储**:PostgreSQL 单一数据库;`tx()` 先 UPDATE scope_locks 串行化全部写者;迁移 pg_advisory_xact_lock + 版本闸门;事件 seq 自增支撑 SSE 游标。
- **worker**:O_EXCL pid 锁 + 存活检测、SIGTERM/SIGINT 优雅退出、心跳状态文件、2s→60s 退避、每周期一个学习块事务、提醒经 reminded_at 恰好一次、来源刷新带日上限/白名单/指数退避(封顶 168h)/内容变更即失效计划。
- **备份恢复**:pg_dump custom 格式 --no-owner --no-acl;暂存 0600 + os.link 原子发布(拒绝覆盖);报告含 SHA-256;恢复校验摘要 + --exit-on-error;恢复演练建临时库比对行数后 DROP WITH (FORCE);状态文件原子写 0600 + fsync;36h 陈旧判定;launchd 每日 03:00 + 14 天保留;凭证不进 dump。
