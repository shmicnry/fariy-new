# P1 收尾与 P2 启动

## 当前交付

P1 新增：显式 schema_version（旧库升级到版本2）、SQLite文件锁/Postgres事务级锁串行初始化、工作队列索引、SQLite一致性快照备份和摘要校验恢复。恢复只创建新数据库，不覆盖任何现有数据库；凭证文件不在数据库备份中，恢复后需重新提供凭证。并发初始化、旧库升级、拒绝未来版本、记忆版本备份恢复及真实Postgres并发写入已纳入回归。

P2 首个闭环：浏览器上传 UTF-8 TXT/Markdown（1 MiB、256000字符上限），材料进入原有队列。worker 每次读取一个1200字符块，保存原文、字符位置、来源、课程与检查点；重启从下一块继续，不重复读取。全部读完进入待人工验证，不自动宣称掌握。新增课程分块查看、关键词检索、带精确原文的练习提交与练习记录；材料删除使课程、分块和练习失效。

文件仅解码为文本，不落用户命名路径、不执行内容、不访问链接。PDF、Office、图片、音视频和 URL 抓取不在本次上传支持范围，相关扩展返回不支持。检索目前是词法检索，不宣称向量或语义检索；练习保存为未评分记录，不宣称通过客观能力测验。

## 操作

```sh
# API与worker使用同一FAIRY_DATABASE_URL，启动方式沿用README
python -m fairy.maintenance backup var/fairy.db /你的备份目录/fairy-snapshot.db
# 记录backup输出的sha256；停止旧服务后恢复到另一个新文件，再切换连接地址
python -m fairy.maintenance restore /你的备份目录/fairy-snapshot.db /新的目录/fairy-restored.db --sha256 备份摘要
```

备份含个人资料，权限为0600。备份不能代替删除策略；历史备份不会随当前记忆遗忘自动销毁。数据库凭证引用可能在另一台机器不可用，恢复并不自动恢复私有密钥。

新增API：POST `/v2/learning/files`、GET `/v2/learning/search`、GET `/v2/learning/courses/{id}/chunks`、GET/POST `/v2/learning/courses/{id}/practice`。文件提交采用JSON/base64，便于复用现有鉴权与幂等协议。

## 阶段门槛与限制

P1本次可靠性范围已有可执行代码和测试，不将整个P1宣称无条件完成：真实云模型验证仍待用户填写地址/模型/密钥，GitHub Actions账号限制未代改。通用指代与事实冲突、向量检索、Keychain集成和金额预留账本仍列为后续增强，不能从本轮通过的有限场景推断通用语义正确。

Postgres验收使用已有Postgres16二进制，在独立临时目录、回环地址和55439端口启动，不接触现有数据库。完整Docker部署与生产备份恢复仍需按部署环境验收。

P2下一批：私有文档解析、来源可信度与时效、检索质量评估、练习评分与留出题、实体/争议/预测记录。自主联网和多媒体处理需各自提供完整的权限、大小/类型边界及失败验收后再启用。
