# P2 学习与世界知识：核心闭环

本轮按P2优先推进，不启用P3–P5功能。

## 已实现

- 文件投喂：沿用UTF-8 TXT/Markdown、分块出处、检查点及断点续读。
- 链接投喂：所有者提交公开HTTPS链接，建立持久导入预留，最多采集一次；不携带凭证或Cookie、不执行网页内容。不自动重试失败导入，重新尝试需要新提交。只接受UTF-8 HTML/纯文本/Markdown；不跟随重定向，不接受压缩正文；限制读取大小和时间。DNS返回的所有地址都必须为公网，再固定其中一个地址建立TLS连接，证书仍验证原始域名，防止DNS重绑定。
- 来源复核：尚未复核、一手、交叉核对、争议、不采纳，附复核理由、方法和可选到期时间。标签来自所有者判断，不是自动真理认证。争议、拒绝、过期来源退出有效记忆、资料检索及新练习评定，相关未执行任务阻塞；复核恢复有效后可续读。来源变化使在途上下文快照失效。
- 世界知识：实体/主题、属性/关系、主张值、精确原文和材料引用。对同一明确实体与属性的不同值显示分歧，不自动选取“真相”。符合当前查询的有效主张可进入本地主模型参考上下文，携带出处、来源等级及冲突信息；不会成为用户个人事实。
- 学习验证：练习附原文，所有者按0–5分量表复核并记录理由，3分以上记为通过。文件及链接课程必须有最近一次通过的练习评定，才能确认完成；旧文字材料接口保留原有人工证据核验兼容行为。
- 效果记录：提交数、已复核数、首次与最近得分、分数变化。明确记录owner_rubric和generalization_verified=false，不把人工分数当模型客观迁移能力评测。

## 真实限制

本机对公开示例网页的实采集被DNS地址规则阻止：当前解析结果未满足公网要求。没有因此放宽私网访问规则，也不宣称真实公网采集成功。采集控制、预留、失败重放、地址校验、重定向拒绝等通过可控测试。实际网页上传、来源复核、主张登记和练习评定通过浏览器验收，报告见p2-browser-results.json。

当前文件解析仅限TXT/Markdown，不支持PDF、Office、图片、音视频或登录态网页；无自动联网选题、自动抓取嵌入资源、向量检索、通用实体消歧、自动考试生成或客观学习能力认证。不能从本轮有限闭环推断完整自主学习。

## API

- POST/GET `/v2/learning/links`：登记与查看导入结果。
- GET `/v2/learning/sources`、PATCH `/v2/learning/sources/{id}`：来源复核。
- POST/GET `/v2/world/claims`：出处主张与显式同键分歧。
- PATCH `/v2/learning/practice/{id}`：CAS量表评定。
- GET `/v2/learning/courses/{id}/effect`：有限样本效果记录。

世界与知识页提供链接投喂、来源复核和主张登记。学习中心提供练习评定、效果查看与完成门槛。争议不等于删除，原文仍可由所有者查看；材料删除沿用原来的级联失效。
