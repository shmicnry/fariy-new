# 云费用预算与原生图标

日期：2026-11-19。

## 云模型费用预算

模型配置新增：

- `cloud_currency`，三位大写币种代码；
- `cloud_input_cents_per_million`；
- `cloud_output_cents_per_million`；
- `cloud_daily_cost_limit_cents`。

金额使用整数百分之一分保存，避免浮点误差。云端派发前按保守方式预留：

```text
预计输入字节数 × 输入单价
+ 最大输出 Token × 输出单价
```

每次调用保存预留金额、价格快照和币种。返回 usage 后按实际 prompt/completion tokens
结算；缺少 usage、超时或取消时保留整笔预留并标记 `unknown`，不会假设免费。

每日费用预算比较“已结算金额 + 在途/未知预留”。超过上限时不发送云请求，
返回 `cloud_daily_cost_limit_reached`。新增 `GET /v2/models/budget`。

管理端显示当日已预留/结算金额、上限、币种，并在调用日志中显示每次云端费用。
本地 Ollama 请求不进入金额账本。

## AppIcon 与 PWA 图标

现有 Fairy SVG 本身有效，但旧 PNG 是损坏的占位图。本次从 SVG 重新渲染并移除透明
通道，生成：

- Xcode AppIcon 全尺寸资源，支持 iPhone、iPad 和 macOS；
- PWA 192、512 图标；
- Apple Touch Icon 180。

所有 PNG 均为无 Alpha 的 RGB 图像。Xcode asset catalog 已加入 App target，
`ASSETCATALOG_COMPILER_APPICON_NAME=AppIcon`。

## 验证

- 实际 cloud usage `30/10` 按配置单价结算为预期微单位；
- 每日金额上限在发往云供应商前拒绝；
- usage 缺失时使用保守预留；
- PostgreSQL 针对性回归：通过；
- iOS Simulator AppIcon 资源编译：通过；
- PNG Alpha 检查：通过。

## 边界

- 单价由所有者填写，不是自动从供应商 API 同步；
- 不进行币种换算；
- 供应商若返回错误 usage，本地账本无法独立审计；
- AppIcon 是现有 Fairy SVG 的位图化版本，尚未包含 App Store 营销图标集。
