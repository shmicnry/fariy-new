## 二、已实现功能全景（均有自动化测试或真实验收）

### P1 · 模型路由与可审阅记忆

- 本地 Ollama 主模型（qwen3:4b 对话、bge-m3 向量、qwen3-vl:4b 视觉），原生 `/api/chat`；每轮可选自动路由 / 仅本机 / 先本机再请副模型。
- 通用云副模型配置（Chat Completions 兼容地址、模型、密钥、升级条件、每日次数），密钥进 CredentialVault 不落明文；Token 单价、派发前预留、实际结算、每日金额硬上限，缺 usage 保守计费。云端默认只收当前问题，发送已确认记忆需显式选择。
- 记忆闭环：提案（逐字出处）→ 确认 → 召回 → 纠正 → 遗忘，全程版本历史；记忆保留逐字原文并标注主体与第三人称事实（用户事实 / 助手信息），饮品偏好等问句只依据对应主体的已确认记录回答。11-17 记录的「茉莉花茶幻觉」「人称错位」两类缺陷已修复并通过 Live Ollama 语义验收。
- 纠正会屏蔽旧对话来源；来源变化或取消后旧模型结果不能提交、不能发云。
- 入口：Web「对话」「记忆审阅」「模型与路由」；API `turns`、`memories`、`memory/proposals`、`models/*`。
- 证据：`tests/test_p1.py`（37）、`test_semantic_memory.py`（7）、`scripts/acceptance_ollama.py` 真实验收通过。

### P2 · 学习与世界知识

- 文件投喂 TXT/Markdown/PDF/DOCX，按页/段落保留出处，扫描 PDF 逐页 Vision OCR；阅读分块、断点续读、带出处练习。
- 链接投喂：SSRF 安全抓取、域名白名单、版本差异摘要、周期检查、每日网络上限、失败退避；来源变化自动创建新来源与课程并失效旧派生记忆。
- 课程 → 练习 → 测验（模型草稿必须人工核对确认后才可执行）→ 评估运行（可取消）→ 学习效果记录；世界知识主张带来源与冲突标记，学习结论可撤销。
- 入口：Web「学习中心」「世界与知识」「学习测验」；API `learning/*`、`sources/*`、`assessments/*`。
- 证据：`test_p2_knowledge.py`（14）、`test_documents_assessment.py`（14）、`test_reliability_learning.py`（7）。

### P3 · 技能与 Mac 感知/受控操作

- 技能注册表：安装 ≠ 授权，限时授权（1–1440 分钟）、启用/停用分离、调用状态持久化。内置 7 个声明式技能（Mac 状态/界面结构/启动允许应用/创建允许文件、学习检索、世界主张查询、自主建议）。
- Mac 只读感知：Swift 桥接读取系统状态、应用清单、允许目录文件、限深 Accessibility Tree、OCR；TCC 权限检测。
- 受控操作（四层门槛：配置开关 + 允许列表 + 有效授权 + 技能启用）：只启动允许列表中的应用（无任意参数、不键入内容）；只在允许目录创建新文件（不覆盖，写后校验字节与 SHA-256）。
- 任意操作执行 `/mac/runs` 明确返回 501，未实现即不假装。
- 入口：Web「技能中心」「Mac 操作」；API `skills/*`、`mac/status|apps|files`。
- 证据：`test_p3_p5.py`（23，含四层门槛与无任意参数测试）、`apps/mac-bridge` 6 项 Swift 测试（错误路径、AX 限额、OCR 往返）、release 二进制契约验证。

### P4 · 多端体验

- 语音：本地 TTS 可用；本地转写已上线（whisper-cli 7.0.13 + ggml-small，中文真实往返约 0.3 秒，音频不落盘、不走云；Whisper 可能输出繁体字，语义不受影响）。模型位于 ~/Library/Application Support/Fairy/models/ggml-small.bin，launchd 服务经 FAIRY_WHISPER_MODEL 注入。
- 入口：Web 全部页面；API `events/stream`、`devices/*`、`voice/*`、`cards`、`approvals`。
- 证据：`test_devices.py`（4）、`test_pet_state.py`（6）、`test_reminders.py`（4）、`scripts/browser_*.cjs` 11 项审计、`scripts/acceptance_whisper.py` 真实转写验收（`whisper-acceptance.json`）。

### P5 · 自主性与进化

- 自主预算账本：目标启动/暂停/继续/完成结算/取消释放，无上限时间自动停机；自主选题候选（域名白名单 + 预算约束）→ 接受成计划 → 启动。
- 进化实验：隔离评测 → 人工批准 → 发布登记（单条当前发布账本）→ 回滚（替代与恢复链、状态守卫）；无人值守演练通过。
- 认知快照 `/cognition/snapshot`；桌宠 PAD 情绪 + 缘起理由（确定性、可解释），皮肤可插拔（Live2D/VRM 配置校验，内置回退可用）。
- 入口：Web「自主与进化」「流程管理」「桌宠与形象」；API `autonomy/*`、`evolution/*`、`cognition/snapshot`、`pet/state`。
- 证据：`test_autonomy_topics.py`（6）、`test_evolution_release.py`（2）、`test_p3_p5.py` 自主部分、发布回滚演练记录。

### 运行保障

- PostgreSQL 16 单一数据库（SQLite 运行支持与旧文件已全部移除），版本迁移；`store.tx(scope)` 行锁事务。
- 常驻 API + worker（launchd），每日 03:00 备份 + SHA-256 + 自动恢复演练 + 保留期清理；备份不含凭据。
- 两轮全量审计修复（`test_audit_gaps.py` 10、`test_audit_round2.py` 8）：云计费、Mac 范围、SSRF、事务、密钥、备份恢复等安全路径。
- Dockerfile / compose.yaml / requirements.lock / 契约导出脚本齐备。

- 所有「未实现」接口都返回明确 501 与原因码，不会静默假装成功。
