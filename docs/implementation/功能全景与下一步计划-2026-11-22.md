## 二、已实现功能全景（均有自动化测试或真实验收）

### P1 · 模型路由与可审阅记忆

- 本地 Ollama 主模型（qwen3:4b 对话、bge-m3 向量、qwen3-vl:4b 视觉），原生 `/api/chat`；每轮可选自动路由 / 仅本机 / 先本机再请副模型。
- 多模型档案与按任务自动切换：本地、云端各最多 8 个档案（模型名、上下文窗口、输出上限、超时；云档案另含地址、单价、独立密钥），对话 / 推理 / 代码 / 写作四类任务各自绑定本地与云档案，每轮按问题内容自动分类并套用对应档案参数；档案密钥独立入 CredentialVault，接口与事件流不回显；旧版配置无档案字段时自动归一化为默认档案。
- 智能任务分类：关键词快路径零成本命中；未命中且配置了任务档案时，用本地模型做一次 ≤8 秒超时的分类（chat/reasoning/code/writing）。分类请求用 `format` 枚举语法把输出约束为单个任务标签，思考型模型（qwen3）的推理进入独立 thinking 字段不污染答案，实测 3–5 秒判对；解析兼容 JSON 字符串与裸词，失败、超时或冷加载一律静默回落 chat，不额外计费、不写事件流；后台「模型与路由」页可开关（`smart_task_routing`，默认开），每轮 `model_route.task_classifier` 标明分类来源。
- 通用云副模型配置（Chat Completions 兼容地址、模型、密钥、升级条件、每日次数），密钥进 CredentialVault 不落明文；Token 单价、派发前预留、实际结算、每日金额硬上限，缺 usage 保守计费。云端默认只收当前问题，发送已确认记忆需显式选择。
- 记忆闭环：提案（逐字出处）→ 确认 → 召回 → 纠正 → 遗忘，全程版本历史；记忆保留逐字原文并标注主体与第三人称事实（用户事实 / 助手信息），饮品偏好等问句只依据对应主体的已确认记录回答。11-17 记录的「茉莉花茶幻觉」「人称错位」两类缺陷已修复并通过 Live Ollama 语义验收。
- 纠正会屏蔽旧对话来源；来源变化或取消后旧模型结果不能提交、不能发云。
- 入口：Web「对话」「记忆审阅」「模型与路由」；API `turns`、`memories`、`memory/proposals`、`models/*`。
- 证据：`tests/test_p1.py`（49，含档案增删改、密钥隔离、任务路由选档、云档案计费回退、旧配置归一化、非法引用校验、智能分类模型兜底/裸词兼容/开关/失败回落）、`test_semantic_memory.py`（7）、`scripts/acceptance_ollama.py` 真实验收通过；`scripts/acceptance_cloud.py` 云端 Live 验收脚本就绪（无可用云配置时输出 skipped 报告 `p1-cloud-acceptance.json`；有密钥后自动验证云端往返、计费结算与每日次数上限，结束后恢复原配置）。

### P5 · 自主性与进化

- 自主预算账本：目标启动/暂停/继续/完成结算/取消释放，无上限时间自动停机；自主选题候选（域名白名单 + 预算约束）→ 接受成计划 → 启动。
- 进化实验：隔离评测 → 人工批准 → 发布登记（单条当前发布账本）→ 回滚（替代与恢复链、状态守卫）；无人值守演练通过。
- 对比进化（借鉴 Harness²）：每个候选附带行为对比（新增通过 / 回退案例，无需标准答案）；增益互斥且无回退时给出组合建议；采纳写「采纳」经验、回滚写「警示」经验，最近 5 条经验注入后续实验；Web 进化页展示对比标签与经验账本。
- 认知快照 `/cognition/snapshot`；桌宠 PAD 情绪 + 缘起理由（确定性、可解释），皮肤可插拔（Live2D/VRM 配置校验，内置回退可用）。
- 入口：Web「自主与进化」「流程管理」「桌宠与形象」；API `autonomy/*`、`evolution/*`、`cognition/snapshot`、`pet/state`。
- 证据：`test_autonomy_topics.py`（6）、`test_evolution_release.py`（2）、`test_duplex.py` 对比/组合/经验账本部分、`test_p3_p5.py` 自主部分、发布回滚演练记录。
